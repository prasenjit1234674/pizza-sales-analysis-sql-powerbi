# 🍕 Pizza Sales Analysis | Power BI & SQL Project

This end-to-end data analysis project focuses on uncovering business insights from pizza sales data using **SQL Server** and **Power BI**. The goal is to help business stakeholders optimize product strategies, boost revenue, and understand customer behavior based on real-world data.

---

## 🎯 Objective

- Analyze 49,000+ pizza sales records to identify key patterns and performance drivers.
- Create a dynamic Power BI dashboard with KPIs and visual breakdowns.
- Use SQL for querying and cleaning raw data efficiently.

---

## 🛠 Tools & Technologies Used

| Tool       | Purpose                           |
|------------|------------------------------------|
| **SQL Server** | Data querying and transformation |
| **Power BI**   | Dashboard and data visualization |
| **Excel**      | Initial data cleaning and exploration |

## 📊 Key Insights

- 💰 Total Revenue: ₹8,17,860  
- 🛍️ Total Orders: 21,350  
- 🍕 Top Performing Pizza: Pepperoni (Large)  
- 📅 Peak Days: Saturday & Sunday  
- ⏰ Peak Hours: 6 PM – 9 PM  
- 📏 Large pizzas generated the most revenue  
- 🔻 Bottom 5 pizzas accounted for <5% of total sales
